# YLA API docs (GitHub Pages branch)

Static YLA API documentation, built from the `mod-yla` method headers with the
PHP docs site on this branch.

Do not edit this branch by hand: `source/` is synced from `master-shadows`
by the `Docs Pages Sync` workflow on every push. The workflow rebuilds the
static site and deploys it to GitHub Pages directly — built output is never
committed here.
