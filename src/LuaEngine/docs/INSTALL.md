# Installing and updating
YLA is installed as a module for Yggdrasilcore. Follow the [Installation steps in the README](../../../README.md#installation) — clone `mod-yla` into your core's `modules` directory and rebuild.

The upstream Eluna project's own install guides (for stock Eluna on MaNGOS/TrinityCore, e.g. [ElunaTrinityWotlk](https://github.com/ElunaLuaEngine/ElunaTrinityWotlk)) do not apply to YLA.

After installing YLA you should check out these:
- [YLA getting started](USAGE.md)
- [YLA features](IMPL_DETAILS.md)

### Updating
Updating is handled like any other module: `git pull` inside the `mod-yla` directory and rebuild the core.
To update the databases refer to the core's official updating documents.
